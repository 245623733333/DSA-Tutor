Project: DSA Tutor
Category: Learning & education
Summary: DSA practice where you earn the answer. Students pick a problem (many framed as everyday Indian scenarios like UPI splits and Blinkit orders), write code, and run real tests in the browser (JavaScript and Python). A five-level hint ladder (Understand, Nudge, Hint, Review, Solution) unlocks help one step at a time. Plain-English bug nudges explain failing tests, a speed check estimates time complexity, hints can be read aloud, a topic map tracks progress, and friend challenges can be shared on WhatsApp. An AI tutor built on the BharatCode API answers questions in English, Hindi, Telugu or Tamil, streams its replies, reads the student's latest code and test result, and remembers each problem's chat. C++ test running works locally with g++; Java and C have a practice mode.
Model: qwen-3.8-27b via the BharatCode API (OpenAI-compatible /chat/completions)
Run: copy .env.example to .env, add BHARATCODE_API_KEY, then run `npm start` (Node 18+).
